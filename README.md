# Mesa de Precatórios

App web de mapeamento e negociação de precatórios.

- `index.html` — o app (publicado no GitHub Pages).
- `dados/base_publica.json` — listagens públicas dos tribunais (TRF3, propostas 2025–2027) e índices de correção; carregadas no primeiro acesso.
- `supabase.sql` — estrutura do banco (Supabase), acesso só dos sócios cadastrados.

Os dados da carteira ficam no banco, nunca neste repositório.
